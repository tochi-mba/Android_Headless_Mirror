Help

When something is not right.

Find the symptom, then the fix. If none of these is it, the last one says how to tell us.

The app says no phone is connected

Check the cable first: charge-only cables have no data lines. Try a port on the PC itself rather than a hub.

Unlock the phone. If it asks to allow USB debugging, tick Always allow from this computer and tap Allow.

If Windows sees the phone but the app does not, the app offers Repair USB driver in the bar above the mirror. See Fix a phone Windows will not read.

Windows says "USB device not recognised"

Windows gave up reading the phone. The app notices within a few seconds and offers Fix USB, which resets the device after one administrator approval, and Fix automatically from now on.

If it keeps happening, try another cable, turn off USB selective suspend in Windows' power options, and choose File transfer in the phone's USB options. rex usb status shows what Windows reports.

The lock screen is black

Some phones mark their secure lock screen as protected, and Android will not stream it. After a restart you may need to unlock on the phone once.

For a pattern lock, the app draws a guide so you can unlock from the PC: see Unlock a phone whose lock screen is black. The pattern is never stored or replayed.

There is no sound from the phone

Phone audio needs Android 11 or later. Check that Phone audio on this PC is on, then restart the mirror: audio settings apply the next time it starts.

Only the main view plays sound; copies are always silent. Some apps refuse to let their sound be captured.

The picture stutters or lags

Lower the resolution or the frame rate, and use USB rather than Wi-Fi. Each copy of the phone asks the phone for another video encoder, so close copies you do not need.

If the picture flickers or stays black, try another renderer.

Keys type the wrong characters

The phone uses its own hardware keyboard layout. Keyboard layout in Controls opens the Android screen where you pick it.

If typing still misbehaves, turn on the compatibility keyboard and restart the mirror.

A copy will not open

Copies need the phone upright and enough room beside it at full height. Make the window wider or close the side panel with Ctrl+Alt+B.

A copy that fails twice is given up on: the phone may have no video encoder left for it.

The app does not start, or closes

The log says exactly why. Open it from the folder below, or run rex diagnostics: it reports the version, the program Windows starts at sign-in and whether it is this one, whether the settings files can be read, and whether scrcpy and ADB run.

Then report the problem with that report attached.

Where the app keeps its files

Installed, the app's own files are in %LocalAppData%\Programs\Android Headless Mirror, and your settings, logs, screenshots and recordings are in %LocalAppData%\REX\Android Headless Mirror.

config.json holds the app's settings, state.json what it remembers about your phones and the window, and logs\mirror.log what happened.

Put every setting back

Settings → Connection & advanced → Reset every app setting. From a terminal, rex config restore undoes the last change made with rex config set.

Uninstall

Windows Settings → Apps → Android Headless Mirror → Uninstall. Your settings stay in %LocalAppData%\REX until you delete that folder.

Privacy and security

There is no account and no telemetry. The app does not upload the mirrored screen, what you type, lock information or anything on the phone. It connects to GitHub only to download itself and the official scrcpy.

USB debugging gives this PC full control of the phone, so only allow computers you trust. The app never stores or types a PIN, password or pattern, and asks for administrator approval only for the USB repairs, through the Windows prompt.

Report a problem

Open a new issue on GitHub, or use Report a problem in the Info tab, which fills in the version. Attach the output of Copy diagnostics (Info tab) or rex diagnostics.
