Command line

Everything from a terminal.

rex.exe is on your PATH after installing. In a checkout, use REX.bat the same way.

For scripts and coding agents

Start with rex agent, or add --json anywhere. Every command then writes exactly one JSON document, never prompts, contains no colour codes, and exits 0 on success and 1 on failure.

{"ok":true,"protocolVersion":2,"command":"status","data":{...}}
{"ok":false,"protocolVersion":2,"command":"action","error":{"type":"InvalidOperationException","message":"..."}}

Ask rex agent capabilities first: it lists every command, action, phone setting and config path this version knows. With more than one phone connected, pass --serial; the command line never guesses between phones.

Every command

Commands marked needs the app act on the open window; start it with rex open first. The rest work on their own, over ADB.

Needs the app

rex sound [0-100|up|down|mute|unmute|toggle]

The phone's sound on this PC: a level, louder, quieter or muted. Without a value, what it is now.

Output
Both: plain text, or JSON with --json
Needs the app
Yes
