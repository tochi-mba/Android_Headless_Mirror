Simple by design

Plug in. Allow once. Use your phone from Windows.

The app takes care of ADB and scrcpy so the everyday path is boring, in the best possible way.

01

Connect over USB

USB is the default and the recovery path. No network setup is needed. Wireless ADB is there if you want it, off by default.

02

Allow this PC

Accept Android's standard “Allow USB debugging” prompt and tick “Always allow from this computer”. That is the only authorisation there is.

03

The mirror opens

The app waits in the tray, notices the phone, wakes it, dismisses the keyguard where Android allows it and opens the mirror. If scrcpy crashes it restarts.

Built for daily use

Everything in one place.

One window. True fullscreen.

Controls, Phone, Settings and Info stay in the side panel. Press F11 to fill your display. A small translucent HUD fades away; move to the top edge for navigation, rotation, Fit and Exit.

Zoom that actually works

Alt + wheel or Alt + pinch scales the real video surface, so clicks land where you see them. A small navigator shows where you are; drag it to pan.

Phone controls

Home, back, recents, power, sleep and wake, volume, notifications, quick settings, rotation, clipboard both ways and screenshots.

Phone settings

Brightness, timeout, forced rotation, dark mode, text size, animations, stay awake, Wi‑Fi, mobile data, airplane mode, display size and density.

Raw Android settings, guarded

Browse and edit the Android settings provider with search and risk labels. Keys that would cut off ADB are protected so you cannot lock yourself out.

Black lock screen? Still usable

Some phones mirror their lock screen as black. For pattern locks the app draws a nine‑dot guide from Android's own layout, with keyboard calibration as a fallback.

Precision touchpad

Pinch like the phone. Hold Alt for the PC.

Two fingers on the touchpad become two real fingers on the phone. Hold Alt and the same gesture moves the PC view instead. There is no ambiguity and nothing to toggle.

No modifier

Pinch, spread, rotate, pan

Both contacts are injected as touches, so TikTok, Maps and Photos see exactly what they would on the glass. Pinch and pan while pinched, just like on the phone.

Alt+
Hold Alt

Zoom and pan the PC view

The phone receives nothing. Alt + pinch zooms the mirror, Alt + two‑finger slide pans it, and the zoom stays after you let go. With a mouse use Alt + wheel and Alt + drag.

Five minutes

Install

  1. Clone or download the repository.
    git clone https://github.com/tochi-mba/Android_Headless_Mirror.git
  2. Run REX.bat. The first run prepares the app from a release, or builds it locally if the .NET 10 SDK is installed, then opens it.
  3. Press Install scrcpy. The official Genymobile release is downloaded and its SHA‑256 checksum is verified before anything is installed.
  4. Enable USB debugging on the phone. Settings → About phone → tap Build number seven times, then Developer options → USB debugging.
  5. Plug the phone in and tap Allow. Tick “Always allow from this computer”. The mirror opens by itself.

Tick Start with Windows in Settings and the app waits in the tray after every sign‑in. Closing the window keeps it running; Quit is in the tray menu.

Scripts and agents

Everything the window does, from the command line.

REX.bat <command> runs rex.exe. Add --json or start with agent and you get exactly one JSON document and no prompts.

rex status                        app, mirror and phone state
rex action sleep                  turn the phone screen off
rex zoom in | out | reset         PC-side zoom of the open mirror
rex screenshot                    save a PNG of the phone screen
rex phone set brightness 180      friendly phone settings
rex android list global --filter animation
rex config set Mirror.MaxFps 90   one-step undo: rex config restore
rex agent capabilities            the machine-readable contract
Questions

FAQ

Does it work with phones other than the Galaxy S21 Ultra?

Yes. Any Android phone with USB debugging works with scrcpy and ADB. The S21 Ultra is the phone the project is developed and tested on, so its quirks are the ones handled best.

Why is the lock screen black on the mirror?

Some manufacturers mark the secure lock screen as protected content, which Android will not stream. After a reboot you may need to unlock on the phone once. For pattern locks the app draws a guide so you can unlock blind afterwards. The pattern itself is never stored or replayed.

Can I still touch the phone while it is mirrored?

Yes. The screen is off, not locked. Tap the power button or press Wake in the app to turn it back on.

Is anything sent anywhere?

No. There is no account, no telemetry and no server. The only download is scrcpy from its official GitHub release, verified by checksum.

What does “Stop mirror” do?

It closes the mirror and stays in the tray. The app will not reopen until the phone reconnects or you press Start. Quit in the tray menu exits completely.

Does it need administrator rights or root?

No. Everything runs as your user with standard ADB permissions. The app never roots, flashes or modifies the phone.
